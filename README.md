This project is a simple and responsive Calculator Web Application developed using HTML, CSS, and JavaScript. The application is designed to perform basic arithmetic operations such as addition, subtraction, multiplication, and division through an intuitive and user-friendly interface.

The calculator features a clean layout with interactive buttons and a display screen that shows both user input and calculation results. JavaScript is used to handle user interactions, process mathematical expressions, and dynamically update the display. HTML provides the structure of the application, while CSS is used to create an attractive and responsive design that works across different screen sizes.

In addition to basic calculations, the project demonstrates key front-end development concepts such as DOM manipulation, event handling, responsive web design, and user interface development. The calculator also includes a calculation history feature that allows users to view recent calculations, enhancing usability and providing a better user experience.

This project was developed as part of my internship task at InternPe and helped me strengthen my understanding of web development fundamentals. Through this project, I gained practical experience in integrating HTML, CSS, and JavaScript to build a functional web application while improving my problem-solving and debugging skills.

Technologies Used: HTML5, CSS3, JavaScript

Key Features:

Basic arithmetic operations
Responsive user interface
Dynamic display updates
Calculation history support
Simple and user-friendly design
Real-time input handling

This project serves as a strong foundation for learning front-end web development and can be further enhanced with advanced mathematical functions, theme customization, and local data storage capabilities.
